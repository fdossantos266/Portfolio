# Portfolio

Mon site perso, en français, portugais et anglais. Fait avec React, TypeScript et Vite.

## Lancer en local

```bash
npm install
npm run dev
```

Build : `npm run build` (sortie dans `dist/`).

## Modifier le contenu

- Infos perso, liens, WhatsApp : `src/data/profile.ts`
- Projets : `src/data/projects.ts` et `src/data/projects-extra.ts`
- Textes du site : `src/i18n/translations.ts`
- Couleurs : `src/styles/global.css`
- Images des projets : `public/projects/`

## Mise en ligne

Déployé sur Vercel depuis GitHub. Chaque push sur `main` met le site à jour.
